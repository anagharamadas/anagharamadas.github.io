### 📚 Trial Reads
**Full-stack AI book companion — FastAPI · Next.js · Supabase**

A ground-up rebuild of Trial Reads as a modern full-stack application. A **FastAPI** backend handles LLM orchestration, natural-language-to-SQL querying, and book recommendations, while a **Next.js (TypeScript/React)** frontend delivers a responsive library manager and chat interface. The app generates chapter-by-chapter book summaries, suggests similar titles with purchase links, and lets you query your personal reading history through a conversational ReAct agent — now backed by a **Supabase (PostgreSQL)** database instead of a local vector store. The backend is deployed on **Render** and the frontend on **Vercel**.
